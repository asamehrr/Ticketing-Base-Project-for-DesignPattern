# Ticketing-Base-Project-for-DesignPattern
تمرین شماره ۲-الگوهای طراحی_شی‌گرایی
---

## توضیح پوشه‌ها

- **بخش صفر-تحلیل** : شامل تحلیل اولیه پروژه و مستندات مرتبط  
- **بخش اول تا بخش چهارم** : محتویات پروژه در مراحل مختلف آموزش و تمرین  
- **بخش دوم** : شامل فایل‌های Word، PDF و دیاگرام UML  
- **بخش سوم** : پیاده‌سازی الگوهای طراحی  
  - اعمال Logging : فایل Java مربوط به Logging  
  - اعمال الگوی Factory : پیاده‌سازی Factory pattern  
  - اعمال الگوی State : شامل اینترفیس State و وضعیت‌های مختلف (5 فایل Java)  
  - الگوی Strategy : پیاده‌سازی Strategy pattern  
  - کلاس Main : اجرای نهایی پروژه  
  - کلاس Ticket : کلاس Context اصلی پروژه  
- **بخش چهارم** : شامل فایل‌های Word و PDF نهایی
